## 本次额外改动

这次把 `testclient/.env` 里的本机预览默认值改成了：

```text
VITE_ALPHA_OUTPUT=ws
```

原因很直接：

- 本机调试的时候，`ws` 不走 packed WebRTC 那层视频编码，连接会更快一点
- 画面也会少一次压缩，通常比 `webrtc-packed` 更清楚一点

如果是远程展示，还是建议改回：

```text
VITE_ALPHA_OUTPUT=webrtc-packed
```

这个模式更适合跨机器访问和展示，但会慢一点，也会软一点。

## EdgeTTS 检查结果

记录时间：2026-06-17 17:30 左右

这次确认下来，TTS 还是优先用 EdgeTTS。

当前 `testclient/.env` 里的相关配置是：

```text
TEST_TTS_PROVIDER=edge
TEST_TTS_SAPI_FALLBACK=0
```

也就是说，服务会先走 EdgeTTS，并且不会在 EdgeTTS 失败的时候再绕到 Windows SAPI。这样比较符合现在的部署方式，也能避免 Linux 或者 uv 环境里出现 Windows-only 的错误。

已经实际测过：

- `http://127.0.0.1:8036/health` 返回正常，并且 provider 是 `edge`
